# 构建产物与版本规则

`build.ps1` 使用 Windows 自带的 .NET Framework C# 编译器构建程序并运行自动检查，不依赖第三方包下载。

`package.ps1` 按明确的文件清单生成以下产物：

| 产物 | 内容 |
| --- | --- |
| `codex-connect-fix-v<版本>-windows.zip` | 可执行程序、中文使用说明、项目说明、许可证、安全说明与验证范围 |
| `codex-connect-fix-v<版本>-source.zip` | 源代码、测试、构建脚本、CI 配置及维护文档 |
| `SHA256SUMS.txt` | 两个 ZIP 文件的 SHA-256 校验值 |
| `release-notes.md` | 版本功能说明与使用条件 |

用户版 ZIP 内另含可执行文件的独立校验值。源码包不包含编译产物、测试数据、用户配置、诊断日志或配置备份。

程序版本由 `src/AssemblyInfo.cs` 定义，manifest 与界面版本应保持一致。打包脚本会校验指定版本与程序集版本是否匹配。

构建产物未声明字节级可复现性，不同构建可能具有不同 EXE 哈希。若对二进制进行代码签名，校验值应在签名后生成。

Windows CI 工作流执行构建、测试和打包，使用固定提交版本的 Actions。构建任务默认只有仓库只读权限，版本标签触发的发行任务单独使用写权限。

完整系统安装、UAC、登录启动和显示缩放的验收范围见 [验证记录](verification.md)。
