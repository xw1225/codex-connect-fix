# 软件架构

Codex 连接修复基于 C#、.NET Framework 4.8 和 WinForms，使用单个 Windows 可执行文件提供中文界面与无窗口后台转发进程。

## 远程设备连接

转发器监听 `127.0.0.2:443`，通过本机 HTTP CONNECT 代理连接固定目标 `chatgpt.com:443`。TLS 字节原样转发，不替换证书、不解密流量。系统 hosts 中的受管理映射将该域名的直连流量引向转发器。

后台以部署用户的普通权限运行，登录时启动。计划任务每分钟触发恢复，已有实例时跳过。关闭工具窗口不会停止后台进程。

## 重连配置

重连修复调用 Codex 桌面版内置 CLI，启用 `respect_system_proxy`。修改前保存当前用户的配置备份，还原时只恢复该开关的原值，保留其他设置及后续修改。

界面分别呈现配置开关、HTTP/WebSocket 检查结果和可还原记录。检测通过说明当前检查正常，不能证明所有重复重连原因都已消除。

## 安装与卸载

安装前检查代理及 TLS 通路，提交 hosts 修改后再次验证。任务和映射必须符合已知格式；未知同名任务、损坏标记和不安全的安装路径会中止自动操作。

支持 `CodexRemoteRelayHelper` 和 `CodexRemoteProxyFix` 两种任务身份。卸载前保存任务与 hosts 备份，仅撤销对应任务和映射，保留程序文件。失败时恢复原配置，并保留任务原有的运行状态。

## 权限与进程管理

安装目录、hosts 和计划任务的修改使用 Windows 提权流程。用户配置操作需要核实当前账户与桌面登录账户一致。管理员启动的界面也会使用受限令牌，以普通权限运行 Codex CLI。

CLI 只继承标准输入输出所需的句柄。进程退出与输出排空共享超时期限，操作专属 Job Object 负责清理派生进程。

## 界面与诊断

两个功能区域各提供一组操作按钮。手动代理端口和诊断详情默认收起；布局根据实际 DPI 和文字测量调整，小窗口支持滚动。

诊断结合计划任务、hosts、监听进程和加密通路判断转发器状态。Codex 自检仅展示配置、登录凭据、HTTP 与 WebSocket 的状态值，不输出原始账号、令牌或日志详情。

验证范围与已知限制见 [验证记录](verification.md)。
